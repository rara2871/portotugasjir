# portotugasslicing
Web Portofolio & Slicing

Situs web portofolio pribadi yang dibuat dari hasil *slicing* antarmuka menjadi kode HTML5, CSS3, dan JavaScript interaktif.

Live Demo: [https://rara2871.github.io/portotugasslicing/](https://rara2871.github.io/portotugasslicing/)

---

Deskripsi
Web ini berisi informasi profil personal, daftar keahlian (skills), portofolio proyek yang telah dikerjakan, serta tautan kontak langsung. Didesain secara penuh menggunakan CSS Flexbox & Grid untuk memastikan tampilan yang responsif di berbagai perangkat (desktop, tablet, dan mobile).

Teknologi yang Digunakan
- HTML5 – Struktur halaman web semantik.
- CSS3 – Kustomisasi gaya, Flexbox, Grid, dan Media Queries responsif.
- JavaScript – Fitur interaktif DOM manipulation.
- Font Awesome – Ikon visual modern.

---

Fitur Utama
- Fully Responsive: Nyaman diakses dari layar HP maupun Monitor Laptop.
- Modern Dark Theme: Antarmuka dengan tema gelap yang estetik.
- Direct Links: Tautan langsung menuju proyek luar dan aksi kirim email (`mailto:`).
